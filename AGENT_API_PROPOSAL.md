# Спецификация REST API для агентов: Pushkin Rhyme Machine

Данный документ описывает интерфейс REST API для прямого подключения внешних автономных агентов и автоматизированных сервисов к механизму рифмования.

---

## 1. Базовые параметры

- **Базовый URL (локально):** `http://localhost:3000/api/v1`
- **Формат обмена:** `application/json; charset=utf-8`
- **Аутентификация:** `Bearer <AGENT_API_KEY>` (опционально в локальном режиме)

---

## 2. Эндпоинты

### 2.1. `POST /api/v1/rhyme/generate`
Преобразует произвольный текст в классическое поэтическое произведение в стиле А.С. Пушкина с моралью.

#### Тело запроса (Request Body):
```json
{
  "text": "Вчера произошел сбой в распределенной базе данных из-за десинхронизации узлов консенсуса.",
  "options": {
    "include_moral": true
  }
}
```

#### Параметры схемы:
- `text` *(string, обязательный)*: Исходный текст (длина от 3 до 4000 символов).
- `options.include_moral` *(boolean, опционально, по умолчанию `true`)*: Включать ли философский вывод.

#### Успешный ответ (200 OK):
```json
{
  "success": true,
  "data": {
    "poem": "Узлы в ночи гласили розно,\nИ сервер пал под бременем забот,\nНо починять систему поздно,\nКогда умолк святой консенсусный оплот.",
    "moral": "Мораль сей басни такова: репликацию блюди без сна и устали.",
    "originalText": "Вчера произошел сбой в распределенной базе данных...",
    "engine": "PushkinRhymeEngine_v2.0"
  }
}
```

---

### 2.2. `GET /api/v1/engine/info`
Возвращает информацию о возможностях движка, шагах обработки и правилах поэтики.

#### Успешный ответ (200 OK):
```json
{
  "name": "Pushkin Rhyme Engine",
  "version": "2.0.0",
  "meter": "Iambic tetrameter (4-стопный ямб)",
  "rhyme_scheme": "ABAB (перекрестная)",
  "stanza_size": 4,
  "supported_features": [
    "text_to_poem_transformation",
    "philosophical_moral_generation",
    "lexical_archaisms"
  ],
  "steps": [
    { "id": "ANALYZING", "label": "Анализ смыслов" },
    { "id": "ARCHAIZING", "label": "Лексическая замена" },
    { "id": "RHYTHM_MAPPING", "label": "Ритмическая сетка" },
    { "id": "RHYMING", "label": "Подбор рифм" },
    { "id": "STYLIZING", "label": "Инъекция стиля" },
    { "id": "COMPLETED", "label": "Формирование морали" }
  ]
}
```

---

### 2.3. `POST /api/v1/rhyme/analyze` *(Перспективный эндпоинт)*
> **Примечание:** В кодовой базе v2.0 данный метод не реализован. При проектировании расширения он будет принимать готовое стихотворение и возвращать оценку метрики и карту рифм.

## 3. Обработка ошибок (Error Codes)

Ответы с ошибками возвращаются в унифицированном формате:

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR | RATE_LIMIT_EXCEEDED | UPSTREAM_GEMINI_ERROR | INTERNAL_ERROR",
    "message": "Описание ошибки для агента"
  }
}
```

- `400 Bad Request` — Пустой текст или превышение лимита символов.
- `401 Unauthorized` — Отсутствует или недействителен токен агента (если включена авторизация).
- `429 Too Many Requests` — Превышен лимит запросов к внешнему ИИ-сервису.
- `502 Bad Gateway` — Недоступность нижележащей модели Gemini.
