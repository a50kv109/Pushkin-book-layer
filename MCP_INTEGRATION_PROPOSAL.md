# Спецификация интеграции MCP (Model Context Protocol): Pushkin Rhyme Machine

Данный документ описывает подключение «Рифменной машины Пушкина» в качестве сервера инструментов по протоколу Model Context Protocol (MCP), разработанному для автономного обнаружения и вызова функций ИИ-агентами.

---

## 1. Концепция MCP-сервера

Агент (клиент MCP) при запуске опрашивает сервер через `tools/list`, получает схемы вызова и при необходимости стилизации текста или создания поэмы вызывает инструмент `generate_rhyme`.

```
┌──────────────────────────────────────┐
│  ИИ-Агент (Claude / Gemini / etc.)   │
└──────────────────┬───────────────────┘
                   │ MCP Protocol (JSON-RPC over stdio / SSE)
                   ▼
┌──────────────────────────────────────┐
│  Pushkin Rhyme Machine MCP Server    │
│  ├── tool: generate_rhyme            │
│  ├── tool: get_engine_info           │
│  └── prompt: pushkin_transform_guide │
└──────────────────┬───────────────────┘
                   │ Внутренний вызов
                   ▼
┌──────────────────────────────────────┐
│  services/geminiService.ts           │
└──────────────────────────────────────┘
```

---

## 2. Экспортируемые инструменты (Tools)

### 2.1. Инструмент `generate_rhyme`
- **Описание:** «Преобразует входной прозаический, новостной или технический текст в классическое русское стихотворение XIX века в стиле А.С. Пушкина (4-стопный ямб, перекрестная рифма ABAB) с ироничной или философской моралью.»
- **Входная JSON-схема (Input Schema):**
```json
{
  "type": "object",
  "properties": {
    "text": {
      "type": "string",
      "description": "Исходный текст, событие или идея для перевода в поэтический слог."
    }
  },
  "required": ["text"]
}
```
- **Результат вызова:** Текстовый блок со стихотворением и моралью, готовый для включения в ответ агента пользователю.

---

### 2.2. Инструмент `get_engine_info`
- **Описание:** «Возвращает параметры поэтического движка, используемую метрику (ямб), схему рифмовки и перечень шагов трансформации.»
- **Входная JSON-схема:**
```json
{
  "type": "object",
  "properties": {}
}
```
- **Результат вызова:** JSON-метаданные об алгоритмических ограничениях и этапах.

---

### 2.3. Перспективный инструмент `analyze_rhyme` *(Статус: Проектирование)*
- **Описание:** «Проверяет готовый текст на соблюдение размера и определяет тип рифм.»
- **Примечание:** Потребует реализации отдельного верификатора метрики, так как в версии 2.0 данный функционал представлен исключительно в виде описательного шага в визуализаторе UI.

---

## 3. Варианты развертывания MCP-сервера

1. **Локальный режим (Transport: `stdio`):**
   - Запуск через команду: `node dist/mcpServer.js` (или `tsx mcpServer.ts`).
   - Идеально для локальных агентов (Claude Desktop, Cursor, командная строка Linux).
   - Безопасно: API-ключи остаются в локальном окружении пользователя, данные не покидают устройство.

2. **Сетевой режим (Transport: `SSE` — Server-Sent Events):**
   - Запуск отдельного HTTP/SSE демона.
   - Подходит для удаленных агентов в облачной среде. Требует авторизации и защиты эндпоинта.
