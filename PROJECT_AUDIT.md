# Технический аудит проекта: Пушкинская Рифменная Машина (Pushkin Rhyme Engine v2.0)

Дата аудита: 2026-11-19  
Статус проекта: Стабильный, готов к публикации на GitHub (при условии принятия решения по лицензии).

---

## 1. Общие сведения

Приложение **«Рифменная машина Пушкина» (Pushkin Rhyme Engine v2.0)** представляет собой веб-приложение на базе React и TypeScript, которое преобразует современную прозу, технические описания или новости в изящную классическую русскую поэзию XIX века в стиле А.С. Пушкина с использованием генеративного искусственного интеллекта Google Gemini.

---

## 2. Технологический стек

- **Фронтенд:** React 19 (`react`, `react-dom`), TypeScript (~5.8.2).
- **Стилизация:** Tailwind CSS (подключен через CDN + кастомные классы для стилизации под пергамент и классическую типографику).
- **Шрифты:** Google Fonts (*Playfair Display*, *EB Garamond*).
- **Интеграция ИИ:** `@google/genai` (модель `gemini-3-pro-preview` с Structured Outputs в формате JSON).
- **Сборщик:** Vite 6 (`vite`, `@vitejs/plugin-react`).
- **Управление зависимостями:** Bun / npm (`package.json`).

---

## 3. Архитектура и структура проекта

- `/App.tsx` — корневой компонент приложения, управляющий состоянием (стадии работы движка, ввод пользователя, результат, ошибки) и координирующий процесс обработки.
- `/components/EngineVisualizer.tsx` — визуализатор этапов работы «механического» движка (анализ, архаизация, ритмическая сетка, подбор рифм, инъекция стиля, мораль).
- `/components/OutputParchment.tsx` — компонент вывода результата в виде старинного свитка (пергамента) с текстом стихотворения и моралью.
- `/services/geminiService.ts` — сервис взаимодействия с Gemini API для получения структурированного ответа (стихотворение + мораль).
- `/constants.tsx` — константы шагов движка и SVG-иконки (перо, чернильница).
- `/types.ts` — TypeScript-интерфейсы и перечисления (`EngineStage`, `TransformationResult`, `EngineStep`).

---

## 4. Пользовательский сценарий (User Flow)

1. **Главный экран (IDLE):** Пользователь видит классическое оформление с чернильницей и пером, а также текстовое поле для ввода прозы или технического описания.
2. **Активация:** При нажатии кнопки «Активировать Модуль» запускается параллельный процесс: реальный запрос к Gemini API и визуальная симуляция прохождения 6 этапов работы движка с интервалом анимации.
3. **Визуализация (PROCESSING):** Интерфейс анимирует прогресс по шагам: «Анализ смыслов», «Лексическая замена», «Ритмическая сетка», «Подбор рифм», «Инъекция стиля», «Формирование морали».
4. **Результат (COMPLETED):** По завершении генерации и симуляции появляется стилизованный пергамент с поэзией и моралью. Пользователь может нажать «Новое вдохновение» для сброса и повторного ввода.
5. **Обработка ошибок (ERROR):** В случае сбоя сети или API выводится корректное сообщение об ошибке с возможностью возврата.

---

## 5. Технические ограничения и особенности

- Требуется действующий `GEMINI_API_KEY` (передается через переменные окружения Vite).
- Зависит от доступности модельного эндпоинта Gemini.
- Отсутствует персистентность на бэкенде (все сессии работают в оперативной памяти клиента).
