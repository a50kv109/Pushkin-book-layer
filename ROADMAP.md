# План развития (Roadmap) — PushkinRhymeEngine 2.0

Актуальная дорожная карта отражает развитие **PushkinRhymeEngine 2.0** от альфа-релиза **Stage C+ (`v0.1.0-alpha`)** к открытой образовательной, творческой и исследовательской поэтической платформе, где поэтика А.С. Пушкина служит исследовательской основой, а ключевым инвариантом выступает принцип **`POETIC FORM MUST NOT OVERRIDE FACTUAL ACCURACY`**.

Подробная техническая спецификация этапов зафиксирована в `UPDATED_PROJECT_ROADMAP.md`.

---

## Завершённые этапы

- [x] **v2.0.0 — Базовое приложение (`IMPLEMENTED`, live API `NOT_VERIFIED`):** React/Vite UI, визуализация `EngineStage`, `geminiService.ts -> transformText()`, CLI и Agent Skill (`4/4` офлайн-тестов).
- [x] **Visual & Narrative Reference Library V1 (`TESTED`):** каталог из 19 якорей, 8 нарративных паттернов, 3 режима работы и текстовый fallback при отсутствии локальных PNG.
- [x] **Stage A–B — Аудит и архитектура (`VERIFIED`):** ревизия `PushkinBookLayer 0.1`, разделение стилизации и текстологии, проектирование `SourceEvidencePackage`.
- [x] **Stage C — Книжный слой и Source Validation (`IMPLEMENTED`, `TESTED`):** пакеты `/book_layer` и `/source_validation`, обработка `FAILED`, блокировка `SCANNED_PAGE`, разделение `semantic_analysis_allowed` / `prosodic_analysis_allowed`, `13/13` автономных тестов на синтетическом PDF.
- [x] **Stage C+ — Подготовка открытого альфа-релиза `v0.1.0-alpha`:** раздельное лицензирование (`MIT` для кода, `CC BY 4.0` для документации), `SECURITY.md`, очистка секретов/персональных данных, исключение неподтверждённых бинарных медиафайлов и локальная фиксация Git-релиза.

---

## Запланированные этапы (`PLANNED`)

- [ ] **Stage D — Проверенный корпус и сегментатор `C1`:** приём открытых текстовых свидетелей, выделение `SCENE`, `SPEAKER_TURN`, `STAGE_DIRECTION`, `VERSE_LINE`, `PROSE_BLOCK` и перебоев стиха.
- [ ] **Stage E — Просодический исследовательский стенд (`C6a` / `C6b`):** детерминированный слогораздел, акцентология с учётом омографии (`AMBIGUOUS_STRESS`), классификатор метра/цезуры/клаузул/рифмы и сверка с `PUSHKIN_PROSODY_BENCHMARK_V1.md`.
- [ ] **Stage F — Реестр поэтических профилей:** извлечение профилей по `PUSHKIN_POETIC_PROFILE_SCHEMA.json` с разграничением `COMPUTED_BY_ENGINE` и `COMMENTARY_ASSERTED`.
- [ ] **Stage G — Контролируемая генерация (`C8`), аудитор (`M8`), серверный API-прокси и Образовательный режим:**
  - вынос `GEMINI_API_KEY` на серверную сторону;
  - подключение детерминированного анализатора к UI при сохранении обратной совместимости `transformText()`;
  - **Образовательный режим (Educational Mode):** интерфейс разбора учебного материала, показывающий:
    1. исходное научное/учебное утверждение;
    2. сгенерированный стих;
    3. использованные ритмические приёмы, размер и рифмовку;
    4. сохранённые ключевые смысловые и фактологические элементы (формулы, условия, причинно-следственные связи);
    5. явное пояснение упрощений, допущенных ради ритма.
- [ ] **Stage H — Сквозная верификация и расширение корпуса:** опциональный трек контролируемого OCR с человеческим ревью (`OCR_HUMAN_VERIFIED`).
