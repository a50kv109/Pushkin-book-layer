# Архитектура интеграции Agent Skill: Pushkin Rhyme Machine

Данный документ описывает гибридную архитектуру репозитория, обеспечивающую одновременное использование приложения человеком (через графический веб-интерфейс) и автономными ИИ-агентами (через систему Agent Skill и CLI-адаптер).

---

## 1. Концепция двойного интерфейса (Dual-Mode Architecture)

Репозиторий объединяет два уровня взаимодействия вокруг единого ядра:

```
                      ┌───────────────────────────────────────┐
                      │            ЕДИНОЕ ЯДРО ДВИЖКА         │
                      │        (services/geminiService.ts)    │
                      │  • transformText()                    │
                      │  • types.ts (TransformationResult)    │
                      └──────────────────┬────────────────────┘
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
   ┌───────────────────────────┐                   ┌───────────────────────────┐
   │    РЕЖИМ ДЛЯ ЧЕЛОВЕКА     │                   │     РЕЖИМ ДЛЯ ИИ-АГЕНТА   │
   │      (Web / Browser)      │                   │     (Agent Skill & CLI)   │
   ├───────────────────────────┤                   ├───────────────────────────┤
   │ • App.tsx                 │                   │ • skills/pushkin-.../     │
   │ • EngineVisualizer.tsx    │                   │   └── SKILL.md            │
   │ • OutputParchment.tsx     │                   │ • agent-interface/        │
   │ • Визуальная симуляция    │                   │   └── cli.ts              │
   │ • Стилизованный пергамент │                   │ • JSON вход / JSON выход  │
   └───────────────────────────┘                   └───────────────────────────┘
```

---

## 2. Структура компонентов

1. **Графический интерфейс (`App.tsx`, `components/`):**
   - Интерактивная среда для конечного пользователя.
   - Воспроизводит пошаговую анимацию механического рифмования.
   - Рендерит результат в стилистике рукописного свитка.

2. **Исполняемый интерфейс агента (`agent-interface/cli.ts`):**
   - Консольная утилита без графических зависимостей.
   - Поддерживает флаги `--input`, `--text`, `--output`, `--key`.
   - Поддерживает стандартные потоки ввода-вывода (stdin / stdout / pipes).
   - Валидирует длину текста (от 3 до 4000 символов) и наличие ключа авторизации.
   - Выполняет динамический импорт существующей функции `transformText()`.

3. **Спецификация способности (`skills/pushkin-rhyme-machine/SKILL.md`):**
   - Формализованное руководство для внешних ИИ-агентов.
   - Описывает триггеры активации, ограничения, протокол вызова и правила представления стихов пользователю.

---

## 3. Схема передачи данных для агента

```
[Внешний ИИ-агент (Claude / Gemini / etc.)]
       │
       │ 1. Обнаружение способности через SKILL.md
       │ 2. Формирование команды запуска
       ▼
[agent-interface/cli.ts]
       │
       │ 3. Валидация входных данных и ключа API
       ▼
[services/geminiService.ts -> transformText()]
       │
       │ 4. Вызов Google Gemini с Structured Outputs
       ▼
[JSON-ответ { success: true, data: { poem, moral, ... } }]
       │
       ▼
[Внешний ИИ-агент обрабатывает и выводит результат пользователю]
```

---

## 4. Преимущества архитектуры

- **Zero Duplication:** Алгоритм рифмования, системный промпт и типы данных не дублируются. Изменение промпта в `services/geminiService.ts` мгновенно отражается как в веб-интерфейсе, так и в CLI агента.
- **Изоляция:** Агентный интерфейс не загружает React, DOM и CSS, потребляя минимум ресурсов процессора и памяти.
- **Готовность к расширению:** В будущем CLI-адаптер может быть легко дополнен сервером MCP (Model Context Protocol) или интеграцией с Belov Fiber SDK без изменения ядра.
