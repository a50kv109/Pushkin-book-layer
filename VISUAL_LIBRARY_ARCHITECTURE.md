# Архитектура подсистемы: Pushkin Visual & Narrative Reference Library V1

**Дата проектирования и реализации:** Ноябрь 2026  
**Назначение:** Подсистема художественной и повествовательной памяти для приложения Pushkin Rhyme Machine, опирающаяся на размеченный корпус визуальных и сюжетных якорей.

---

## 1. Архитектурные принципы

1. **Независимость от метрики и просодии:** Библиотека не встраивается в алгоритмы рифмования и стихотворного размера (`services/geminiService.ts -> transformText()`). Она выступает внешним поставщиком образного и сюжетного контекста.
2. **Паттерны вместо «просто картинок»:** Хранилище описывает переиспользуемые художественные закономерности (композицию, среду, архетипы персонажей, действия, декор, цвет и повествовательные отношения).
3. **Разделение художественной стилизации и исторического факта:** Каждый якорь содержит обязательное поле `historical_status` и `source_type`, фиксирующие, что представленные сцены и открытки являются современными стилизациями, а не документальными источниками.
4. **Сохранение оригиналов и отделение метаданных:** Все 19 загруженных изображений сохранены в неизменном виде в `/public/assets/aistudio/` под исходными именами. Метаданные хранятся отдельно в JSON-каталогах `/data/visual-library/`.
5. **Расширяемость за пределы Крыма:** Схема включает поле `literary_space`, а интерфейс позволяет добавлять новые якоря (например, Михайловское, Болдино, Петербург, Кавказ).

---

## 2. Поток данных и интеграция с движком

```
USER REQUEST
     │
     ▼
VISUAL ANCHOR SELECTION (Выбор 1..N якорей в библиотеке)
     │
     ▼
NARRATIVE PATTERN SELECTION (Отношения: Поэт + Море / Фонтан / Спутники)
     │
     ▼
GENERATION CONTEXT (services/visualLibraryService.ts)
     │
     ├──► MODE 1: Visual Generation Brief (промпт-бриф для открытки/иллюстрации)
     ├──► MODE 2: Poem Illustration Matcher (лексический подбор якорей под стих)
     └──► MODE 3: Narrative Inspiration ──► transformText() ──► OutputParchment
```

---

## 3. Структура модулей

- **`VISUAL_ANCHOR_SCHEMA.json`** — формальная JSON Schema (Draft 2020-12) структуры визуального якоря.
- **`types/visualLibrary.ts`** — TypeScript-контракты (`VisualAnchor`, `NarrativePattern`, `LibraryCategory`, `LibraryMode`, `PoemMatchResult`, `VisualGenerationBrief`).
- **`data/visual-library/visual-anchors.json`** — каталог 19 фактически инспектированных и размеченных изображений.
- **`data/visual-library/narrative-patterns.json`** — каталог 8 повторяющихся повествовательных паттернов.
- **`services/visualLibraryService.ts`** — сервисный слой:
  - загрузка каталога и локальных правок из `localStorage`;
  - фильтрация по 11 категориям и текстовому поиску;
  - Режим 1 (`buildVisualGenerationBrief`);
  - Режим 2 (`matchPoemToAnchors` — прозрачный лексический подбор по основам русских мотивов, без имитации скрытого ИИ-анализа);
  - Режим 3 (`buildNarrativeInspirationContext` + `transformTextWithVisualContext`, вызывающий неизменённую функцию `transformText()`).
- **`components/visual-library/`**:
  - `VisualLibraryView.tsx` — галерея, панель фильтрации, панель выбранных якорей и переключатель режимов;
  - `AnchorDetailModal.tsx` — карточка якоря, просмотр с приближением, связанные якоря и ручной редактор метаданных;
  - `ModeStudioPanel.tsx` — рабочая студия для Режимов 1, 2 и 3;
  - `AddAnchorModal.tsx` — добавление пользовательских якорей из иных литературных пространств.
- **`App.tsx` и `components/OutputParchment.tsx`** — навигация между «Рифменной машиной» и «Художественной библиотекой», передача выбранных якорей в генерацию и кнопка быстрого подбора иллюстрации к готовому стиху.
